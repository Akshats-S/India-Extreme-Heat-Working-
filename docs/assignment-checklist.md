# Submission requirements

Course: Introduction to Environmental Economics, AY 2026-27.
Team: Akshat Srivastava, Krishna Reddy and Jatin Shetty.

## Preliminary assessment: 6 November 2026

The team-provided handoff specifies a preliminary cleaned dataset, preparation
code and a brief topic outline. The preliminary package includes those items,
one short README containing the topic outline/run instructions, plus the raw
inputs, preparation settings and dependencies
needed to run the code. Its daily table has 140,256 rows and 16 columns.
Final-stage documentation, tests, build records, heat outputs and figures are
excluded from the preliminary hand-in. Validation/coverage reports are generated
when the code runs; they are not bundled as extra deliverables.

The provided course PDF does not separately specify this checkpoint.

## Final assessment: 30 November 2026

The [course handout](handout/Instructions.pdf) specifies a self-contained folder
that reproduces the cleaned dataset without manual preparation steps:

- README with source links, coverage, environmental economics relevance and
  every cleaning/preparation step in order.
- Complete code and inputs needed to regenerate the dataset.
- Two or three candidate questions, each with policy relevance and an
  applicable course technique.

The final package includes all of these, plus the extended daily dataset,
threshold/annual/period tables, three candidate applications, sensitivity
tables, five figures, computed results and verification records.

Evaluation covers topic/question novelty, economics links, dataset coverage,
correct reproducible code and clear cleaning instructions. The instructor has
confirmed full AI assistance is permitted. Topic registration and project
data-sharing arrangements are resolved; IMD source attribution is retained.
